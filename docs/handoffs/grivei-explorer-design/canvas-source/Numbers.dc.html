about the numbers

One counting rule, and what it leaves out

Every money number in the explorer is awarded value, counted the same way in totals, on the map, in rankings, in the Flow lens and in Signals. Each total says what it left out and links to those Records.

Awarded value

Awarded value is the amount SEAP publishes when a contract or a direct purchase is awarded, in RON. It is the only measure the explorer sums. It is not what was paid.

Framework agreements

A framework agreement carries a ceiling, the most it can reach. The ceiling is shown and never summed. The subsequent contracts signed under it are summed, and each one is linked to its framework by the award notice number.

Consortia

A Record won by several suppliers counts once, in full, for the contracting authority. For each supplier it counts as an equal share. The equal split is a convention: SEAP does not publish how members divide the money.

Suspect values

Some published values are data-entry errors. A Record with a suspect value is shown, searchable and badged, but it is left out of every sum and of every Signal.

Works are told apart by contract type or a CPV code starting with 45. Rents under CPV 70 and other exempt categories are never flagged.

Blank values

A Record with a blank or zero value reads “no value in SEAP”. It counts as a Record and adds nothing to sums, so a blank is never read as zero spending.

Contract modifications

Modifications are not loaded. A value is the value at award. One exception: contracts from 2021 and 2022 awarded without a prior call come from a later crawl, so their value is as of the crawl date, which the Record shows.

Supplier identity

A supplier is its CUI, when the CUI passes the check digit and ANAF confirms it. The name shown is ANAF's current official name, and the page lists every spelling found in SEAP. A supplier with no usable CUI is “identified by name only”. A natural person is shown as “Persoană fizică”, never named or linked. The few identities corrected by hand read “identity curated”.

Signals

A Signal is a set of Records worth verifying in the source documents. It is not an accusation. Signals are counted, listed by date or by RON, and never turned into a score. Each one links to the filter that reproduces it.
