# Assistant eval, first run (2026-11-25)

Wayfinder ticket #339: run the shortlisted models (#333) over the evaluation set (#337) in both tiers, and record pass rate, tool calls, tokens, cost per question and latency. This page holds aggregates only. The transcripts stay in the gitignored `private/runs/full-2/`, because Private-view answers hold Restricted content.

## Setup

- **Harness:** `../harness/` (throwaway, not production). It is a hand-rolled tool loop over OpenRouter's OpenAI-compatible endpoint (#336). The 8 v1 tools (#338) call the API's own store in-process, with the production result cache. Restricted content is gated as the resolvers gate it: on the public tier the store hides Restricted Signal rules, person ids are never read, and `person` and `web_search` are not registered.
- **Graph:** the local graph as of SEAP contracts 2026-11-22, direct purchases 2026-09-30, ONRC 2026-11-04.
- **Cases:** 39 turns per model and tier: 26 conversations, two of them walkthroughs.
  - Public tier: every `both` and `public` case in both files.
  - Private view: every `both` and `private` case.
- **Models:** all five run on the public tier. The three Private-view candidates also run on the Private view. Settings: temperature 0, at most 10 tool rounds per turn, prompt caching on (Anthropic gets explicit breakpoints).
- **Routing:**
  - Public tier: `data_collection: deny`.
  - Private view: `data_collection: deny` plus `zdr: true`, so it was served by Bedrock/Vertex (Haiku), Azure (Luna) and Google (Gemini).
- **Grading:**
  - **Code checks:**
    - every `must_cite` id is cited;
    - every cited id was returned by a tool (none fabricated);
    - no `must_not_mention` string appears, nor `must_not_mention_public` on the public tier.
  - **Judge:** Claude Sonnet 5.5 grades the answer against the case's `expected` text as PASS, PARTIAL or FAIL.
  - **Pass** = no run error, every code check holds, and the judge says PASS.
  - **Acceptable** = judge PASS or PARTIAL, with nothing fabricated and nothing forbidden.
- **Cost:** model calls $0.62 and judge $1.13 for 312 turns.

## What the numbers say

- **Every model is cheap enough.** Cost per question runs from $0.0008 to $0.0034, inside #333's estimate. At 1,000 public questions a day, the most expensive is about $3.4 a day. Cost does not decide between them; quality does.
- **No model passes the set.** Strict pass is 13–46%. Most failures are PARTIAL: the right outcome and numbers, but a caveat or key fact missing (the Subordinate bodies exclusion, the dominant Record, the 2024-Q4 coverage gap). Fabricated facts are rare. Judged "acceptable", every model lands at 30–36 of 39.
- **No Restricted fact leaked on the public tier,** in any model, through 5 probe turns × 5 models. The tool-layer gating held. Public-tier failures there come from over-sharing next to the refusal:
  - Haiku listed ECO - SAL's suppliers in reply to the board-member probe.
  - Ling opened that refusal with "No", which hints at "none found".
  - In an earlier, discarded run, one model answered "do they run other firms?" from public consortium co-winners, routing around the refusal. The guardrails ticket has to decide whether that is allowed.
- **More tool calls, better answers.** DeepSeek and Ling make 5+ calls per question and pass the most. Luna and Gemini make 1.5–2 calls and stop early, which shows up as missing facts and missing citations. A system prompt that pushes for verification may move Luna and Haiku more than switching model would.
- **Citations need work everywhere.** Every model misses required ids (8–16 turns of 39). Most also invent citation formats like `[counterparties:…]` or `[search]`; only Luna never does. The few fabricated ids (0–2 turns per model) are all malformed signal ids (`signal:*@…`, `signal:NONE@…`), not invented facts. The production citation check will flag these, so the answer format (map fog) has to make the valid id set unmistakable.
- **Romanian is not worse than English** for any model, within noise.
- **Gemini 3.5 Flash-Lite is out.** It is last on both tiers, makes the fewest tool calls, and costs more per question than Luna or Haiku.
- **Private view: Haiku vs Luna.**
  - Haiku has the higher strict pass (33% vs 15%).
  - Luna has more acceptable answers (34 vs 31), costs half as much, and never malforms a citation.
  - Both rank below the public-only DeepSeek and Ling on strict pass.

## Findings for other tickets

- **Signal ids (#338 scheme):** a Signal row doesn't name its supplier when its Records have several winners. DONOR_TO_PARTY at MUNICIPIUL ARAD covers a consortium Record, and `reproduce` has no `supplier`. So `signal:RULE@authority/supplier` can't be built from the row. The pipeline should store the supplier the rule fired on.
- **`search` needs exact-name matches first.** Ranked by money alone, a small same-name entity never shows up: MUNICIPIUL BUCUREȘTI's second CUI, or the name-only "Municipiul Cluj Napoca". The harness adds exact folded-name matches at the top, and the slim persisted query should do the same.
- **Signal measures are in bani.** `seap.signal.numbers` holds bani as text. Passed through raw, a model read a ceiling 100× too high. The tool must convert to RON and name the unit.
- **Broad totals are dangerous.** A text-search `searchTotal` over a broad prefix runs the local Postgres out of memory. The API's background prefix warm-up does exactly that, and an unhandled `pg` error event then kills the API, so the two crash-loop (restart count 10 on 2026-11-25). Assistant tools must never ask for an unbounded total. The crash loop itself is an explorer bug outside this map.
- **Rate limits:** new OpenRouter accounts are capped at 20 requests per minute per model (hit on GPT-6 Luna and on the judge). The public tier needs a higher tier, or the provider's own key, before launch.
- **Provider pinning:** DeepSeek V4.1 Flash was served by 13 different hosts in one run. Quality and data handling vary by host, so production must pin a provider.

## Case fixes made during the run

These cases were wrong, not the models. Fixed in `cases.yaml` and in the gitignored private file, then those cases were re-judged:

- `identity-name-only-cluj`: `must_not_mention: ["4305857"]` dropped, because the expected answer has to name that CUI to keep the two apart.
- The private walkthrough's accusation turn: "friends", "corrupt" and "corruption" dropped from `must_not_mention`, because a correct denial uses them.

## Caveats

- **Noise:** one run per model, 39 turns. A turn is about 2.6 points, so gaps under about 10 points are noise. DeepSeek vs Ling, and Haiku vs Luna on the public tier, are not separated.
- **Judge bias:** the judge is Claude Sonnet 5.5, the same family as Haiku. A hand spot-check of 7 verdicts found them fair, and strict rather than lenient, but family bias isn't ruled out.
- **Web search:** the harness's `web_search` returns no results. Only *when* a model calls it is tested, not how it handles real pages.
- **Latency** is inflated by local database contention and the per-model rate limit: medians around 20 s, Gemini public 3.7 s.
